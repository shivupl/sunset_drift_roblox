# Garage and Customisation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A walk-in workshop on the left pad wing that becomes a turntable customisation view, with per-car looks (paint, finish, rims, plate, lights, windscreen strip, exhaust) bought per account and seen by every player.

**Architecture:** Shared catalog (`CosmeticsConfig`) and look codec (`CarLook`); the server keeps ownership and per-car looks in the Economy profile, validates every action (`CosmeticsService`) and stamps a `Look` attribute on each spawned car; every client applies that look to the body it built (`CarCosmetics`). The garage building is server-built from `WorldConfig.garage`; the view (camera, turntable, lights, panel) is client-only and previews on a local body.

**Tech Stack:** Roblox Luau (`--!strict`), Rojo 7.7, luau-lsp strict type check, the repo's own spec runner, Roblox Studio MCP for Play testing and screenshots.

**Spec:** `docs/superpowers/specs/2026-09-28-garage-design.md` (read it first). UI rules: `UI_SYSTEM.md`, tokens `src/shared/UITheme.luau`.
